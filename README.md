# udemy-clone
📚 Udemy Clone

A responsive front-end clone of the Udemy homepage built using HTML5 and CSS3. This project replicates the layout and design of Udemy, helping me practice modern web development concepts such as Flexbox, CSS Grid, responsive design, and clean UI implementation.

🚀 Features
Responsive Navigation Bar
Search Bar
Course Categories
Hero Banner
Recommended Courses Section
Popular Courses Section
Course Cards with Ratings & Prices
Topics Section
Responsive Footer
Clean and User-Friendly UI
🛠️ Technologies Used
HTML5
CSS3
Flexbox
CSS Grid
Font Awesome Icons
Google Fonts (Gabarito)
📖 What I Learned
Building responsive layouts
Using Flexbox and CSS Grid
Creating reusable components
Structuring HTML efficiently
Improving UI design with CSS
